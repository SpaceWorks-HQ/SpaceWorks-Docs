## Find your path

<CardGrid>
  <Card title="Self-hosters" icon="laptop">
    Pick a deployment, run the installer, point a domain at it and keep it updated and backed up.
    Start with [Requirements](/install/requirements/) and the [one-line installer](/install/one-line-install/).
  </Card>
  <Card title="Makerspace staff" icon="open-book">
    Set up your space, invite staff, add inventory and QR labels, then run loans, printing and
    events. See [Set up your makerspace](/guides/makerspace-setup/).
  </Card>
  <Card title="Developers" icon="seti:python">
    Run the stack locally, learn the architecture and the rules that keep it safe, and contribute.
    Start with [Local development](/develop/local-development/).
  </Card>
  <Card title="Integrators" icon="puzzle">
    Use the REST API, signed API clients, webhooks and the device protocol for printers and
    kiosks. See the [API overview](/api/overview/).
  </Card>
